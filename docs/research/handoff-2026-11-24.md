## Working rules learned

- Pre-register gates and floors before running. Never move a kill criterion after seeing data.
- Pass operating facts (`<id>.operating.json`) to the evaluator; never a bare `.intent.json`.
- Pin `PYTHONHASHSEED=0` in evaluation jobs. Size kaeq memory from measured peaks.
- Never cap the Python evaluator at KiCad's 40 GB `ulimit -v`; use `KAE_EVAL_VMEM_KB`.
- Plainly-right fixes need no LLM decision entry. Real design trade-offs do.
